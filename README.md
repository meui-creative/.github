# meui-creative/.github

The public face of the [Meui Creative](https://meui-creative.com) GitHub organization.

- [`profile/README.md`](profile/README.md) is what shows on [github.com/meui-creative](https://github.com/meui-creative).
- [`profile/assets`](profile/assets) holds the animated SVGs and clips it uses. They are generated; don't edit them by hand.
- [`scripts`](scripts) generates them. Run `scripts/build.sh` (or `--fast` to skip re-encoding the client clips).
